# Разработка, тесты и незакрытые проверки

## Тесты

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
```

Тесты идут и на Windows, и на Linux: `fcntl` подключается условно, а вместо сокета агента в тестах
подставляется заглушка. Часть проверок читает тексты `bootstrap.sh` и документации — это не косметика:
инварианты установщика (не печатать секреты, не подставлять плейсхолдер вместо адреса, ждать
состояния, а не кода возврата пакета) иначе ничем не удержать.

## Что здесь не проверено

- Что молчащий, но поднятый туннель AmneziaWG остаётся «в сети» — это вывод из механики
  (`PersistentKeepalive = 25` + окно по трафику), а не замер на конкретном узле. Если такой туннель
  однажды прочитается как «НЕТ В СЕТИ», правится одним числом — `HANDSHAKE_TTL` в `app/presence.py`.
- Как быстро гаснет бейдж «В СЕТИ» после того, как туннель реально закрылся: порога «закрылось →
  нет соединений» никто не измерял.
- Внешний вид на узких экранах и поведение живого UI после деплоя — глазами оператора;
  автоматизированная проверка только структурная.
