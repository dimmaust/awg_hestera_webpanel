# AWG Console

Веб-панель для одного сервера Ubuntu 22.04/24.04 `amd64` с тремя VPN: **AmneziaWG**, **Hysteria2** с
обфускацией и **MTProto-прокси** на движке `telemt`. Пользователи, профили и ссылки, «кто в сети
сейчас», Fail2ban и шифрованные бэкапы — в одном интерфейсе. Один инстанс = один узел.

## Установка на голый сервер

```bash
git clone https://github.com/dimmaust/awg_hestera_webpanel.git /root/awg-panel-src
cd /root/awg-panel-src
sudo ./bootstrap.sh
```

Один прогон поднимает весь стек шестью этапами — пакеты, AmneziaWG, панель, Hysteria2, `telemt`,
Fail2ban — и после каждого этапа проверяет фактическое состояние узла, а не код возврата пакета.
Чужие бинарники закреплены по sha256, ключ репозитория Amnezia — отпечатком: не совпало — скрипт
останавливается и не запускает непроверенный код от root. Узел он не перезагружает, `ufw` не включает,
`sshd_config` не правит и чужие конфиги не удаляет (старые — в `.bak-<дата>`).

Две вещи скрипт за вас не решает:

- **Адреса для белого списка Fail2ban.** Бан идёт на второй неудачной попытке, и без `ignoreip` узел
  забанит того, кто его ставит, а разблокировать будет некому. В терминале этап `fail2ban` спросит
  ваши адреса по одному на строку (IPv4 или CIDR); угадывать их он не пытается. Без терминала — CI,
  `ssh -T` без pty, `curl | bash` — спросить негде, поэтому адрес передают явно:
  `OPERATOR_IPS=203.0.113.10 sudo -E ./bootstrap.sh`.
- **Пароль администратора.** Логин задаётся `ADMIN_LOGIN` (по умолчанию `admin`), пароль генерируется
  при первом запуске, печатается в конце прогона только в терминал запуска и не попадает в логи.
  Первый вход сразу требует его заменить.

Про порядок этапов, флаги `--check` / `--stage` / `--skip` / `--force-config`, первый вход и чек-лист
приёма — [`docs/install.md`](docs/install.md). Другой подготовки, кроме root-доступа к узлу, не
требуется: `git clone` берёт и сам скрипт, и код панели, и шаблоны конфигов, а пакеты, Docker,
репозиторий Amnezia и права на каталоги этапы ставят сами.

## Если прокси на узле уже стоят

`install.sh` ставит только панель: Docker, код в `/opt/awg-panel`, хост-агент, юниты, ключ бэкапов и
jail'ы. Интерфейс AmneziaWG, сервер Hysteria2 и движок `telemt` он не касается — на голой Ubuntu их не
будет, и панель поднимется без единого прокси.

```bash
sudo ./install.sh                        # панель на 127.0.0.1, доступ через SSH-туннель
sudo ./install.sh --with-fail2ban        # + jails для sshd, входа в панель и Hysteria2
sudo ./install.sh --expose-firewall      # привязка 0.0.0.0 и правило ufw
```

## Как устроено

Два слоя. Веб-слой (`app/`, FastAPI + SQLite) живёт в контейнере под непривилегированным uid, с
`cap_drop ALL` и read-only корнем, и файлов узла не видит. Всё, что требует прав root, делает
`host-agent/agent.py` по жёсткому списку операций — без passthrough команд и без пользовательских
строк в shell. Пользователи Hysteria2 при этом живут только в базе панели: сервер спрашивает её по
HTTP, поэтому их создание не требует привилегий на хосте. Клиенты MTProto живут только в движке
`telemt`: панель ходит в его Control API и ничего не пишет на диск.

## Что стоит знать про секреты

- Приватный ключ клиента отдаётся ровно один раз и нигде не сохраняется; секреты MTProto живут в
  движке, а не в базе панели. Ключи AWG, obfs-пароль и токены остаются в узловых конфигах и наружу
  не печатаются вовсе.
- Архивы бэкапов шифруются, но **в них лежит приватный ключ сервера** — `/etc/awg-panel/backup.key`
  нужно скопировать с узла сразу после установки, иначе архивы бесполезны.
- Панель отдаёт plain HTTP: доступ либо через SSH-туннель, либо `--expose-firewall` с правилом ufw.
- Полная переустановка узла обесценивает все ранее выданные ссылки абонентов — §6 в `docs/install.md`.
